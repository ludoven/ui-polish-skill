# UI 审查清单

用于截图、现有页面、设计稿或 UI 代码审查。输出要具体、可执行，避免空泛审美词。

## 1. 整体观感判断

用 3-5 句话判断界面整体设计水平，必须覆盖：

- 是否显得廉价、过时、模板化或 AI 味重。
- 是否像个人开发者随手拼出来的界面。
- 是否符合目标平台和产品类型的专业审美。
- 当前界面最大的问题是什么。
- 哪些元素最影响第一眼观感。

必须指出具体界面元素，不要只说“整体还不错”或“需要优化”。

## 2. 廉价感 / AI 味来源

逐项指出不专业感来源，使用这个格式：

```text
问题位置：
为什么不好：
造成的观感：
应该如何调整：
```

重点检查：

- 过度圆角、强阴影、渐变、玻璃拟态、霓虹色。
- 卡片套卡片、所有内容都装进卡片。
- 无意义大留白或过密堆叠。
- 颜色过多、主色滥用、状态色不准确。
- 字体层级混乱，所有文字都像同一个权重。
- 图标风格、线宽、尺寸、填充比例不统一。
- 按钮、标签、卡片缺乏真实产品质感。
- 内容布局像模板站、Demo 页面或组件展示页。
- 文案空泛，像 AI 生成说明语。

## 3. 具体视觉问题

### 3.1 布局与信息层级

检查：

- 页面主次是否清晰，用户第一眼应该看哪里。
- 是否有元素抢夺视觉焦点。
- 模块是否太散、太挤或太空。
- 是否有过多同级卡片导致没有重点。
- 顶部区域是否过重，内容区是否过轻。
- 操作区、内容区、状态区是否分工明确。

输出建议时说明：

- 哪些模块应该前移、降级、合并或删除。
- 哪些内容应该从卡片变成列表、分割线、表格、工具栏或普通区域。
- 移动端、桌面端、大屏端是否需要不同布局密度。

### 3.2 间距与密度

检查：

- 页面外边距是否适合目标设备。
- 模块间距是否统一。
- 容器内部 padding 是否过大或过小。
- 图标与文字距离是否合理。
- 标题、正文、说明文字之间的垂直间距是否自然。
- 列表项、表格行、工具栏高度是否适合输入方式。

常用默认值：

```text
手机页面左右边距：16 / 20 / 24
桌面内容边距：24 / 32
TV 安全边距：48 / 64
卡片内边距：12 / 16 / 20
模块间距：16 / 24 / 32
图标与文字间距：8 / 12
标题与正文间距：4 / 6 / 8
移动端列表项高度：48 / 56 / 64
桌面列表项高度：32 / 40 / 48
TV 可聚焦项高度：64 / 72 / 80
```

单位按平台换算：Compose 用 dp/sp，Flutter 用 logical pixels，SwiftUI 用 pt，Web 用 px/rem，桌面框架用 DIP/pt。

### 3.3 字号与字体层级

判断当前字号是否过大、过小、过粗、缺乏层级，或辅助文字可读性差。

通用层级参考：

```text
页面标题：22-28
一级模块标题：16-18
正文内容：14-16
辅助说明：12-13
标签/状态文字：11-12
按钮文字：14-15
```

桌面工具和数据面板可以更紧凑；TV、大屏和远距离阅读需要放大。辅助文字优先弱化颜色，不要缩到不可读。

### 3.4 颜色

分析颜色是否专业、克制、统一，是否有明确主色和文本层级。

检查：

- 背景是否过灰、过白、过脏或过花。
- 主色是否使用过多。
- 文本颜色层级是否清晰。
- 分割线、边框、禁用态是否自然。
- 状态色是否和语义一致。
- 是否存在颜色太多导致模板感。

中性默认参考：

```text
页面背景：#FFFFFF / #F7F8FA / #F8F9FB
卡片背景：#FFFFFF
主文本：#1C1C1E
次级文本：#6E6E73
弱文本：#8E8E93
分割线：#E6E8EB
弱边框：#E5E7EB
主色：#3B82F6 / #2563EB
成功色：#22C55E
警告色：#F59E0B
错误色：#EF4444
```

如果项目已有品牌色或平台语义色，优先使用现有系统。

### 3.5 对齐

检查：

- 标题、正文、按钮、图标是否在同一视觉轴线上。
- 多个卡片、列表项、表格列的左边界是否统一。
- 图标尺寸是否造成视觉偏移。
- 右侧操作、状态标签、计数器是否对齐自然。
- 顶部导航、内容区、底部操作是否横向错位。

必须指出具体位置，不要只说“注意对齐”。

### 3.6 图标

检查：

- 线性图标和面性图标是否混用。
- 图标尺寸、线宽、圆角、填充比例是否一致。
- 图标是否像默认素材或装饰过多。
- 图标颜色是否过重或过淡。
- 图标底板是否过多导致页面杂乱。

常用参考：

```text
普通图标尺寸：20 / 22 / 24
小图标尺寸：16 / 18
图标线宽：1.5 / 2
图标与文字间距：8 / 12
```

### 3.7 圆角、阴影、边框

检查：

- 哪些圆角过大。
- 哪些卡片不需要阴影。
- 哪些边框应该删除。
- 哪些区域应该用分割线、留白、标题层级或表格结构替代卡片。
- 是否存在卡片套卡片。
- 是否所有元素都加圆角导致幼稚感。

参考值：

```text
普通卡片圆角：10 / 12
大容器圆角：14 / 16
按钮圆角：8 / 10 / 12
输入框圆角：8 / 10 / 12
弱边框：#E6E8EB
阴影：默认删除；必要时只保留极轻微 elevation / shadow
```

### 3.8 状态、响应式与可访问性

检查：

- loading、empty、error、disabled、selected、hover、focus、pressed 状态是否完整。
- 触控目标、鼠标 hover、键盘焦点、遥控器焦点是否适配输入方式。
- 深色模式是否存在反差不足或颜色失真。
- 文案变长、本地化、动态字体后是否溢出。
- 对比度、点击区域、焦点可见性、screen reader label 是否可接受。

## 4. 应删除或弱化的元素

使用这个格式：

```text
删除对象：
删除原因：
替代方式：
预期效果：
```

覆盖卡片、阴影、渐变、边框、图标底色、装饰元素、空泛文案、过度抢眼按钮或标签。

## 5. 推荐改版方向

给出 2-3 个适合当前产品的方向，并推荐其中一个。

可选方向：

- 极简专业工具风
- iOS 风格轻量卡片
- 克制 Material 3 现代风
- macOS 桌面软件风
- 高级数据面板风
- 专业开发者工具风
- 消费级轻量 App 风
- 品牌内容页 / 官网视觉风
- TV / 大屏聚焦式界面
- 游戏 HUD / 沉浸式界面

每个方向说明适合原因、视觉关键词、颜色建议、布局建议、组件风格和不适合使用的设计元素。
